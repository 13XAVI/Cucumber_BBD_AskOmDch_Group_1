# Askomdich Website – Selenium BDD Automation Framework

## 📌 Project Overview
This project is an automated test framework built to validate the **Askomdich e-commerce website** using **Selenium WebDriver** with **BDD (Behavior-Driven Development)** principles powered by **Cucumber**.  
The framework focuses on ensuring the reliability, functionality, and user experience of core business features such as **Product Exploration, Cart Management, and Checkout flows**.

---

## 🎯 Objectives
- Automate critical user journeys on the Askomdich website
- Improve test coverage and reduce manual testing effort
- Enable readable and business-friendly test scenarios using BDD
- Support **Smoke**, **Regression**, and **Functional** testing
- Generate clear and detailed test reports for stakeholders

---

## 🧩 Framework Design
The framework follows:
- **BDD Approach**: Test scenarios written in plain English using Gherkin
- **Page Object Model (POM)**: Separates test logic from UI locators
- **Reusable Components**: Common utilities for browser setup and waits
- **Scalable Structure**: Easy to add new features and test cases
- **DOM Interaction Layer**: Provides structured access to web elements via the Document Object Model
